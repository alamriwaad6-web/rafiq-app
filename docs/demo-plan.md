# خطة فيديو Demo لرفيق

سجّلي الشاشة من المحاكي أو جهاز Android بعد تشغيل النسخة النهائية. مدة مقترحة: 60 إلى 90 ثانية. استخدمي حسابًا تجريبيًا وبيانات غير شخصية، ثم ارفعي الفيديو وأضيفي رابطه في `README.md`.

1. **البداية (5–10 ثوانٍ):** افتحي رفيق واعرضي شاشة التعريف والانتقال إلى الدخول.
2. **الحساب (10–15 ثانية):** سجّلي الدخول بالحساب التجريبي. إذا لم يكن موجودًا، اعرضي إنشاءه مرة واحدة فقط.
3. **التحدي (15–20 ثانية):** أضيفي مهمة دراسية واضحة، وحددي تصنيفها ووقتها؛ ثم اعرضي ظهورها في الرئيسية.
4. **التركيز (15–20 ثانية):** افتحي المهمة، غيّري مدة الجلسة إلى دقيقة واحدة لتناسب التصوير، وابدئي المؤقّت. يمكن تسريع هذا الجزء في المونتاج.
5. **الإنجاز (10–15 ثانية):** أكملي الجلسة وأظهري تغيّر حالة المهمة والنقاط والمستوى أو ملخص التقدّم.

قبل التسليم، شغّلي الفيديو مرة كاملة للتأكد من وضوح النصوص، عدم ظهور بريدك أو كلمة مرورك الحقيقية، وأن كل خطوة معروضة حدثت داخل التطبيق بالفعل.
